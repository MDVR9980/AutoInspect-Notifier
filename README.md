# AutoInspect Notifier

A fully modular, production-ready desktop application for managing Iranian vehicle inspection reminders.

## Features:
-   **Customer Management**: SQLite backend for storing customer and vehicle data.
-   **SMS Notifications**: Automatic and scheduled SMS reminders via the Ghasedak provider.
-   **Data Import**: Supports both manual data entry and batch import from Excel files.
-   **Database Backup**: Automatic daily backups and on-demand backup creation.
-   **Theming**: Includes a modern Dark/Light theme switcher.
-   **Architecture**: Clean and modular (core/ui/data separation) for easy maintenance.
-   **UI**: Built with the modern PyQt6 framework.

Supports Shamsi (Jalali) calendar dates.
